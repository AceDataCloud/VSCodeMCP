# AceDataCloud MCP bundle — retired

The legacy `acedatacloud.acedatacloud-mcp` VS Code extension has been retired.
Remove it from VS Code and install only the current service extensions you need
from the [AceDataCloud publisher](https://marketplace.visualstudio.com/publishers/acedatacloud).

The maintained MCP servers and individual extensions live in
[AceDataCloud/MCPs](https://github.com/AceDataCloud/MCPs).

The extension was removed from VS Code Marketplace on 2026-10-04.
This repository no longer publishes extension updates or accepts release dispatches.
